## Antria 0.2.0 — Run your own AI team

The Founders Office desktop app is now **Antria**. Same idea, sharper: one sentence in, a whole team of AI teammates on it — talking to each other before they hand you the work.

### What's new
- **Antria rebrand** — new name, refreshed airy editorial look, and calmer pebble-style teammate avatars across the office.
- **Claude *or* Codex — your choice** — pick the engine your team runs on. Bring your Claude account, or run on OpenAI Codex. One-click restart when you switch.
- **Smoother connections** — fixed the connector setup and login hand-off so tools link on the first try, with no silent hangs.
- **Steadier long tasks** — reliability fixes so big multi-step jobs run to the finish instead of dropping midway.

### Install
- **Mac:** download the `.dmg` — signed and notarized by Apple.
- **Windows:** download `Antria-Setup.exe`.

Existing installs auto-update to this build.
