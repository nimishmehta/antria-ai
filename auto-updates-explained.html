Auto-updates are wired up

Your app can now update itself in the background — on both Mac and Windows. Here's what's built, how each release will work, and the two small things I need from you to switch it on for real.

What's done Built & verified

A quick note on the tool: Sparkle is made for a different kind of Mac app and only covers Mac. Your app is built with Electron and ships on Mac and Windows, so we used electron-updater — the standard for your exact setup. Same "set it up once, ~2 minutes per release" experience you were promised, and it updates your Windows users too.

  • The update engine is installed and wired into the app.
  • On launch, the app quietly checks for a newer version, downloads it in the background, and installs it the next time the app is closed — the user does nothing.
  • If the update server is ever unreachable, the app just carries on normally — no crashes, no error pop-ups.
  • Set up to work for both Mac and Windows from one place.
  • A plain-English release checklist is saved alongside this file.

Every future release — about 2 minutes

Once the two items below are set, shipping an update is this simple:

  1. Bump the version number.
  2. Run the one build command — it produces the Mac and Windows update files automatically.
  3. Upload those files to your update folder (drag & drop), replacing the old ones.
That's it. Every installed app picks up the new version on its own within a launch or two. No app-store review, no emails to users, no reinstalls.

Host chosen: GitHub Releases Configured

You picked GitHub Releases — free, nothing to run, and uploads are drag-and-drop (or fully automatic). The app is now pointed at it. Two small handoffs from your side flip it live:

1. Which GitHub repo + upload key

Tell your team which GitHub repository should hold the releases (I've left a labeled blank for its name), and create a one-time GitHub upload key so builds can post themselves. Both are a 2-minute setup — steps are in the release checklist.

2. Turn on Apple "notarization"

Good news — your app is already signed with your Apple developer identity. Apple just needs one "notarize" step switched on, or Mac updates silently won't install for users. It's a small config change using your Apple account. (Windows works without it.)

Once those two are in, shipping an update is: bump the version → run one command → click "Publish" on GitHub. Your Mac and Windows users update themselves from there.
